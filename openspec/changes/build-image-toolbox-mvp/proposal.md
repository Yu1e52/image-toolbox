# Proposal

## Why

学生日常有大量轻图片处理需求：报名照换底色、图片压缩到上传限制、裁剪尺寸、加水印。现有在线工具要么收费、要么把照片传到别人服务器（证件照隐私风险）。做一个纯浏览器本地处理的图片工具箱，零上传、零费用、离线可用，作为作品集里「不依赖任何 key 就完整可用」的项目。

## What Changes

- 新建纯前端 Web 应用：Vue3 + Vite，无后端、无外部 API
- 通用图片编辑：裁剪、缩放、压缩（质量/目标体积）、格式转换（PNG/JPEG/WebP）、文字水印
- 证件照工具：纯色背景智能抠图换底色（红/蓝/白）、一寸/二寸尺寸预设、六寸相纸排版导出
- 所有处理 MUST 在浏览器 Canvas 内完成，图片 MUST NOT 上传到任何服务器

## Capabilities

### New Capabilities

- `image-editing`: 本地图片的裁剪、缩放、压缩、格式转换与水印，处理结果可下载
- `id-photo`: 证件照换底色、标准尺寸裁切与排版打印导出

### Modified Capabilities

（无 —— 全新项目，无既有规格）

## Impact

- 全新项目 `image-toolbox/`，不影响其他项目
- 运行依赖：vue；开发依赖：vite、@vitejs/plugin-vue；无后端、无数据库
- 隐私：图片数据只存在于浏览器内存，页面关闭即消失
