# id-photo 规格增量

## Purpose

把普通照片变成可用的证件照：对纯色背景照片智能抠图换底色，按一寸/二寸等标准尺寸裁切，并排版到六寸相纸上导出，方便直接打印。

## ADDED Requirements

### Requirement: 纯色背景换底色

系统 SHALL 对纯色背景（白/蓝/红等）的证件照自动分离前景与背景，并替换为用户选择的目标底色（红/蓝/白/自定义色）。抠图 MUST 在浏览器本地完成。对非纯色背景的照片，系统 MUST 明确提示效果受限，MUST NOT 假装抠图成功。

#### Scenario: 白底换蓝底

- WHEN 用户载入白底证件照并选择蓝色底
- THEN 预览中背景变为蓝色、人物主体保留，边缘无明显残留白边

#### Scenario: 复杂背景提示

- WHEN 载入的照片背景颜色方差超过纯色判定阈值
- THEN 系统提示「背景非纯色，换底效果可能不佳」，仍允许用户继续尝试

### Requirement: 标准尺寸裁切

系统 SHALL 提供证件照尺寸预设：一寸（295×413px）、二寸（413×579px）、小二寸（413×531px），并支持自定义毫米尺寸与 DPI。裁切 MUST 保持目标宽高比，用户 MUST 能拖动调整取景范围。

#### Scenario: 一寸裁切

- WHEN 用户选择一寸预设并确认
- THEN 输出图片为 295×413 像素

### Requirement: 排版导出

系统 SHALL 把裁切好的证件照按所选尺寸排版到六寸相纸（1800×1200px，300DPI）上，自动计算可排数量并留裁切间距，导出单张可直接打印的图片。

#### Scenario: 一寸八张排版

- WHEN 用户用一寸照片生成六寸排版
- THEN 导出 1800×1200 图片，含按网格整齐排列的多张一寸照与裁切间距
