# 图片工具箱

纯前端图片处理工具：**裁剪 / 缩放 / 压缩 / 格式转换 / 文字水印 / 证件照换底与排版打印**。
零后端、零 API key、零上传——所有处理都在浏览器 Canvas 内完成，图片数据只存在于内存，关闭页面即消失。

## 功能

| 页面 | 能力 |
| --- | --- |
| 通用编辑 | 可视化裁剪（自由 / 1:1 / 4:3 / 16:9，8 向控制点）、等比缩放、质量压缩、**二分逼近目标体积**（如「压到 200KB 以内」）、PNG / JPEG / WebP 互转、文字水印（平铺 / 右下角，字号颜色透明度可调） |
| 证件照 | 纯色背景自动抠图换底（红 / 蓝 / 白 / 自定义色，容差与羽化可调）、一寸 295×413 / 二寸 413×579 / 小二寸 413×531 / 自定义毫米+DPI 裁切、六寸相纸 1800×1200 @300DPI 排版导出（留 2mm 裁切间距） |

诚实性约定：背景方差超过阈值时明确提示「背景非纯色，换底效果可能不佳」，不假装抠图成功；目标体积不可达时如实提示并给出最小结果。

## 启动 / 构建 / 部署

```bash
npm install        # 安装依赖（仅 vue / vue-router / vite）
npm run dev        # 开发服务器 http://localhost:5172
```

路由使用 hash 模式（`/#/editor`）且 `base: './'`，子路径部署与刷新均无需服务端重写规则。

## 抠图算法原理（纯色背景）

O(n) 单遍像素扫描，无模型、无 flood-fill：

1. **背景估计**：取顶部边缘左/中/右三块小补丁（边长 ≤16px，证件照肩膀会占满底部两角，只有顶部一定是背景），求平均色作为背景色 `bg`；同时计算补丁内像素到均值的均方距离作为**方差**。方差 > 900 判定为非纯色背景，UI 明确提示效果受限。
2. **色度距离生成 alpha 遮罩**：对每个像素计算与 `bg` 的欧氏 RGB 距离 `d`：
   - `d ≤ 容差T`（默认 60）→ alpha = 0（背景，全透明）
   - `d ≥ T + 羽化F`（默认 50）→ alpha = 255（前景，全保留）
   - 中间过渡带 → alpha 线性插值，边缘自然羽化
3. **前景去色污染**：过渡带像素是前景与背景的混合 `C = a·F + (1−a)·bg`，按估计的 alpha 反解 `F = (C − (1−a)·bg) / a`，消除白底换蓝底时常见的「白边」。
4. **换底合成**：把带 alpha 的前景合成到目标底色上：`out = F·a + target·(1−a)`。

局限（规格明确不做）：渐变 / 阴影 / 复杂背景效果差，只提示不假装成功；AI 语义分割列为后续增强。

## 压缩二分策略

`canvas.toBlob(type, quality)` 的体积随质量单调不减，但无解析反函数，因此用**二分搜索质量参数**逼近目标体积：

1. 先试 `q = 0.95`：已达标直接返回（不牺牲多余画质）；
2. 再试 `q = 0.05`：仍超标则如实返回「不可达」与最小结果；
3. 否则在 `[0.05, 0.95]` 二分**最多 8 轮**：达标则抬下界并记录最优，超标则压上界；
4. 返回满足目标的最大质量结果（体积最接近目标且画质最好），UI 显示前后体积对比与编码轮数。

PNG 为无损格式，质量参数无效，目标体积压缩仅对 JPEG / WebP 开放。

## 排版计算

六寸相纸 152.4×101.6mm @300DPI = 1800×1200px，间距 2mm ≈ 24px：

```
cols = floor((1800 + gap) / (照片宽 + gap))
rows = floor((1200 + gap) / (照片高 + gap))
```

行列向下取整、网格整体居中。一寸可排 5×2 = 10 张，二寸 4×2 = 8 张。毫米换算 `px = round(mm / 25.4 × DPI)`。

## 隐私

- 不发起任何携带图片数据的网络请求（无后端、无统计、无 CDN 运行时依赖）
- 图片仅存在于 Canvas / 内存，下载通过本地 Blob URL 完成
- 断网状态下构建产物仍可完整使用

## 桌面 exe

- 打包：`npm run dist:exe`（自动构建前端 + 生成不含死文件的干净 Electron 发行版 + electron-builder portable），产物 `release-build/image-toolbox-portable.exe`，单文件双击即用，无需安装 Node
- 原理：Electron 45 主进程直接 loadFile 本地 dist/index.html（hash 路由 + 相对路径，file:// 可用）
- 纯前端项目，窗口直接加载本地 dist/index.html，无内置服务、零上传。
- 已实测：portable 外壳解压→应用启动→窗口渲染正常；本开发沙箱需附加 --no-sandbox 参数（Chromium 沙箱受限），正常 Windows 桌面双击即可
- 数据目录默认 %LOCALAPPDATA%/image-toolbox，可用环境变量覆盖（便携模式）
